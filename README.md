# Fun-Chat

## To check the application:
1. Install Node.js
2. Fork this repository: https://github.com/Arthur-Iorbalidi/fun-chat-server
3. Clone your newly created repo
4. Go to project folder
5. install the dependencies with `npm i`
6. Rename .env.example to .env and change the port if you need
7. start the local server using `npm run start`
8. Go to deployed application https://arthur-iorbalidi.github.io/Fun-Chat/dist
